# Kej — macOS 한·영·일 입력기

영문 자판으로 입력하면 단어마다 한국어·영어·일본어를 구분하는 입력기입니다.
macOS 13 이상, Apple Silicon·Intel을 지원합니다.

이 저장소는 설치 파일과 안내만 공개합니다. 앱 소스와 인증서 개인 키는 포함하지 않습니다.

## 명령어로 설치 시작

터미널에 아래 한 줄을 입력하세요. Homebrew·Xcode·GitHub 로그인은 필요하지 않습니다.

```sh
curl -fsSL https://raw.githubusercontent.com/skizo-io/kej-releases/refs/heads/main/install.sh | /bin/bash
```

공증된 DMG를 내려받아 체크섬·개발자 서명을 확인한 뒤 설치 앱을 엽니다.
열린 창에서 **설치**를 누르세요. 보안 설정을 끄거나 관리자 암호를 입력할 필요가 없습니다.
기존 학습 자료와 설정은 보존하며 이전 앱은 복구용으로 보관합니다.
원격 스크립트 실행이 부담되면 아래 DMG를 직접 다운로드하세요.

## 파일로 설치

[최신 공증 DMG 다운로드](https://github.com/skizo-io/kej-releases/releases/latest/download/Kej-0.2.0.dmg)

DMG를 열고 `Kej 설치.app`을 실행합니다. 정상적인 macOS 첫 실행 확인은 표시될 수 있습니다.
업데이트도 같은 방법으로 진행하며 입력 소스를 다시 추가할 필요는 없습니다.

## 처음 한 번 설정

1. 시스템 설정 → 키보드 → 입력 소스 → 편집… → **＋ → 한국어 → Kej**를 추가합니다.
2. 메뉴 막대의 입력 메뉴에서 Kej를 선택합니다.
3. 설정 창이 설치 전부터 열려 있었다면 ⌘Q로 종료한 뒤 다시 엽니다.

- 오른쪽 **Option**을 단독으로 눌렀다 떼기: 현재 단어의 읽기 변경.
- 오른쪽 **Command**를 단독으로 눌렀다 떼기: 일본어 입력 켜기/끄기.
- **Space**: 확정·띄어쓰기. 일본어는 한자 후보를 표시합니다.

## 확인 범위

0.2.0은 Developer ID 서명·Apple 공증·Gatekeeper 검사와 설치기 보존 검사를 통과했습니다.
다른 Mac의 최초 설치 실사용과 Intel 실기 확인은 아직 별도 미확인입니다.
입력 내용은 서버로 보내지 않으며 학습 자료는 사용자 Mac에 저장합니다.

자료 출처와 이용 조건은 [NOTICE.md](NOTICE.md)를 확인하세요.
설치 파일 공개는 Kej 소스 코드나 상표에 대한 사용 권한을 부여하지 않습니다.
